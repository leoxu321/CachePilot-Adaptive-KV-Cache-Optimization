quality.txt contains original prose written for the CachePilot regression corpus.
It is dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

It is intentionally small and not a standardized language-model benchmark.
No claim is made about training-set contamination, broad task accuracy, or
representativeness. The exact bytes and selected token IDs are hashed in results.
